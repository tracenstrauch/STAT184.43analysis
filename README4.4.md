# STAT184.43analysis

# HW 4.3: Reproducible Data Analysis

## Overview
This repository contains my Quarto file and final PDF report for HW 4.3, which covers:
1. **Diamonds:** Summary tables for diamond length, width, and depth across different color categories.
2. **BIG10:** Scatter plot comparing average points scored versus points allowed per game.
3. **Monte Carlo:** Simulation estimating the area under a chi-square curve across four sample sizes.
4. **Calcium:** Data wrangling plan and comparison of ChatGPT graphs made with a plan versus a generic prompt.

## Files
- `hw43.qmd` — Quarto file with all R code, text, and the appendix.
- `hw43.pdf` — Final rendered PDF report.
